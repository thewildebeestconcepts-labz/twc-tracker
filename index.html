Option A — All-in-GAS
  1. 1Google Sheet → Extensions → Apps Script
  2. 2Paste 6 files (Code.gs + 5 HTML/JSON)
  3. 3Set Script Properties (SHEET_ID, GEMINI_API_KEY, AUTH_PEPPER)
  4. 4Run initializeSheets_() then seedSuperAdmin_()
  5. 5Deploy → Web App (Me / Anyone) → copy URL
Option B — GAS API + GitHub Pages
  1. 1script.google.com → New project → paste api/Code.gs
  2. 2Set Script Properties + enable Gmail API
  3. 3Deploy → Web App (Me / Anyone) → copy /exec URL
  4. 4Push github-pages/* to a GitHub repo, set <meta gas-api-url> to the /exec URL
  5. 5Repo Settings → Pages → main branch → live!
CORS note for Option B: GAS can't answer a CORS preflight (OPTIONS), so the frontend POSTs with Content-Type: text/plain and the JSON in the body — app.js already does this. Don't change it to application/json.
